# RNN과 LSTM: 이전 정보를 Hidden State로 전달하는 방법

문장, 음성, time series처럼 순서가 있는 데이터는 현재 값만 봐서는 이해하기 어렵다. 현재 token의 의미가 이전 token에 따라 달라질 수 있기 때문이다.

RNN(Recurrent Neural Network)은 이전 step의 hidden state를 다음 step으로 전달한다.

$$
h_t = f(W_xx_t + W_hh_{t-1} + b)
$$

```text
x1 -> h1 -> h2 -> h3
           ↑     ↑
           x2    x3
```

핵심은 같은 weight를 모든 timestep에서 공유하면서 과거 정보를 $h_t$에 압축하는 것이다. 문제는 sequence가 길어질수록 오래된 정보까지 gradient를 전달하기 어렵다는 점이다. LSTM은 이 문제를 gate와 cell state로 완화한다.

## RNN의 동작 방식

RNN은 현재 입력 $x_t$와 이전 hidden state $h_{t-1}$를 함께 사용해 새로운 state $h_t$를 만든다. 이 state가 다음 timestep으로 넘어가 일종의 memory 역할을 한다.

![rnn unrolled diagram]({{ '/assets/images/blog/rnn-unrolled.png' | relative_url }})

RNN은 어느 timestep의 output을 사용할지에 따라 여러 형태로 구성할 수 있다.

### 일 대 다(one-to-many)

하나의 입력에서 sequence output을 만든다. Image captioning처럼 image 하나를 입력받아 여러 token을 생성하는 문제가 예시다.

### 다 대 일(many-to-one)

Sequence 전체를 읽고 하나의 값을 출력한다. Sentiment classification이나 spam detection에 사용할 수 있다.

### 다 대 다(many-to-many)

Sequence를 입력받아 sequence를 출력한다. Machine translation이나 sequence labeling이 대표적이다.

Framework에서는 마지막 hidden state만 받을 수도 있고 모든 timestep의 state를 받을 수도 있다. Keras RNN의 `return_sequences=True`는 각 timestep의 output을 모두 반환한다.

## RNN 학습

RNN은 Backpropagation Through Time(BPTT)으로 학습한다. Recurrent computation을 시간축으로 펼친 뒤 마지막 loss에서 이전 timestep 방향으로 gradient를 전달한다.

![bptt overview]({{ '/assets/images/blog/rnn-bptt.png' | relative_url }})

$U$, $V$, $W$는 공유되는 weight이고, $x$는 현재 입력, $s$는 hidden state, $y$는 output이다.

![rnn equations]({{ '/assets/images/blog/rnn-backprop-equations.png' | relative_url }})

각 timestep의 error를 합쳐 total loss를 만들면 공유 weight는 여러 timestep에서 받은 gradient의 합으로 update된다.

Weight $W$는 모든 timestep에서 사용되므로 각 경로의 gradient가 반복해서 곱해진다. 이때 activation derivative와 recurrent weight가 1보다 작으면 gradient가 timestep을 거슬러 갈수록 0에 가까워질 수 있다. 반대로 반복 곱이 너무 크면 exploding gradient가 생긴다.

```text
긴 sequence backward
gradient × W × activation' × W × activation' × ...
          └ 작으면 vanishing, 크면 exploding ┘
```

이 때문에 기본 RNN은 멀리 떨어진 token 사이의 장기 의존성을 학습하기 어렵다.

## LSTM

LSTM(Long Short-Term Memory)은 기본 RNN의 장기 의존성 문제를 완화한다. Hidden state와 별도로 cell state $c_t$를 두고, gate가 정보를 지우고 쓰고 출력하는 비율을 정한다.

### LSTM 구조

기본 RNN은 매 step마다 hidden state 전체를 하나의 nonlinear transformation으로 바꾼다. LSTM은 cell state에 additive update path를 만들고 세 gate로 정보 흐름을 제어한다.

![lstm cell structure]({{ '/assets/images/blog/lstm-cell.png' | relative_url }})

### 셀 상태

Cell state $c_t$는 장기 정보를 전달하는 경로다. 이전 state에서 얼마나 남길지, 새로운 후보 정보를 얼마나 더할지를 다음 식으로 결정한다.

$$
c_t = f_t \odot c_{t-1} + i_t \odot \tilde{c}_t
$$

곱셈으로 지울 정보와 덧셈으로 추가할 정보가 분리되어 있어 기본 RNN보다 gradient가 긴 경로를 지나기 쉽다.

### 망각 게이트

Forget gate $f_t$는 이전 cell state를 얼마나 남길지 결정한다.

$$
f_t = \sigma(W_f[x_t,h_{t-1}] + b_f)
$$

Sigmoid output이 0에 가까우면 해당 정보를 지우고 1에 가까우면 유지한다.

### 입력 게이트

Input gate $i_t$는 새로운 후보 정보 $\tilde{c}_t$를 얼마나 cell state에 쓸지 결정한다.

$$
i_t = \sigma(W_i[x_t,h_{t-1}] + b_i)
$$

$$
\tilde{c}_t = \tanh(W_c[x_t,h_{t-1}] + b_c)
$$

Tanh가 후보 값을 만들고 sigmoid가 write 비율을 정한다.

### 출력 게이트

Output gate $o_t$는 현재 cell state 중 어떤 정보를 hidden state로 내보낼지 정한다.

$$
o_t = \sigma(W_o[x_t,h_{t-1}] + b_o)
$$

$$
h_t = o_t \odot \tanh(c_t)
$$

### 전체적인 수식

![lstm equations]({{ '/assets/images/blog/lstm-equations.png' | relative_url }})

전체 흐름을 정리하면 다음과 같다.

```text
forget gate -> 이전 cell state에서 무엇을 지울지 결정
input gate  -> 현재 입력에서 무엇을 쓸지 결정
cell state  -> 장기 정보를 다음 timestep으로 전달
output gate -> 현재 hidden state로 무엇을 내보낼지 결정
```

## RNN과 LSTM 비교

| 항목 | RNN | LSTM |
| --- | --- | --- |
| 전달 state | Hidden state | Hidden state + cell state |
| Update | 하나의 recurrent transformation | Forget, input, output gate |
| 장기 의존성 | Gradient vanishing에 취약 | 상대적으로 안정적 |
| 계산 비용 | 작음 | Gate 계산으로 더 큼 |

LSTM도 긴 sequence의 모든 정보를 완벽하게 기억하는 것은 아니다. Gate를 추가해 기본 RNN보다 정보와 gradient를 오래 전달할 수 있게 만든 것이다.

## 내가 이해한 핵심

RNN의 핵심은 이전 정보를 hidden state 하나에 계속 압축하는 것이다. 구조는 단순하지만 BPTT에서 같은 weight와 derivative가 반복해서 곱해지므로 오래된 정보까지 gradient를 보내기 어렵다.

LSTM은 이 문제를 다음처럼 바꾼다.

> State 전체를 매번 덮어쓰지 말고, 무엇을 지우고 쓰고 읽을지 gate로 나누자.

Cell state의 additive path와 gate 덕분에 장기 의존성을 기본 RNN보다 잘 다룰 수 있다. 이후 GRU와 selective SSM을 볼 때도 “어떤 정보를 state에 남길 것인가”라는 관점이 그대로 이어진다.
