머신러닝 알고리즘을 볼 때 먼저 구분해야 하는 것은 **무엇을 예측하려는가**이다. 연속적인 값을 예측하면 회귀 문제이고, 정해진 클래스를 고르면 분류 문제다. 그 위에서 모델이 데이터를 나누는 방식, 여러 모델을 합치는 방식에 따라 선형 회귀, 로지스틱 회귀, 의사결정트리, 앙상블 같은 방법으로 나뉜다.

## 선형 회귀

선형 회귀는 입력과 출력 사이의 관계를 직선으로 설명하려는 모델이다.

$$
y = wx + b
$$

여기서 `w`는 기울기, `b`는 절편이다. 모델은 데이터에 가장 잘 맞는 `w`와 `b`를 찾는다. 예를 들어 공부 시간으로 시험 점수를 예측하거나, 집의 면적과 방 개수로 가격을 예측하는 식이다.

입력 변수가 하나면 단순 선형 회귀이고, 입력 변수가 여러 개면 다중 선형 회귀가 된다.

$$
y = w_1x_1 + w_2x_2 + \cdots + w_nx_n + b
$$

선형 회귀의 장점은 해석이 쉽다는 점이다. 각 feature의 가중치를 보면 어떤 변수가 예측에 얼마나 영향을 주는지 대략적으로 볼 수 있다. 반대로 데이터의 관계가 비선형이면 직선 하나로는 표현력이 부족하다.

실제로 선형 회귀를 사용할 때는 feature scale도 중요하다. 어떤 feature는 값의 범위가 0~1이고, 어떤 feature는 수천 단위라면 학습 과정에서 특정 feature가 과하게 영향력을 갖는 것처럼 보일 수 있다. 그래서 표준화나 정규화를 적용한 뒤 모델을 학습하는 경우가 많다.

또 하나 봐야 할 것은 residual이다. 예측값과 실제값의 차이가 특정 구간에서만 크게 나타난다면, 단순한 직선 모델로는 데이터의 패턴을 충분히 설명하지 못한다는 신호일 수 있다.

## 로지스틱 회귀

로지스틱 회귀는 이름에는 회귀가 들어가지만 주로 **이진 분류**에 사용된다. 선형 결합 결과를 sigmoid 함수에 넣어서 0과 1 사이의 확률로 바꾼다.

예를 들어 메일이 스팸일 확률이 `0.8`이면 스팸으로 분류하고, `0.2`이면 정상 메일로 분류할 수 있다. 보통 기준값을 `0.5`로 두지만, 문제에 따라 threshold는 조정한다.

로지스틱 회귀는 출력이 확률이라 해석하기 좋다. 다만 선형 경계를 기본으로 하므로 복잡한 비선형 패턴은 feature engineering이나 더 복잡한 모델이 필요하다.

분류 문제에서는 accuracy만 보면 부족할 때가 많다. 예를 들어 스팸 메일이 전체의 1%밖에 없다면 모든 메일을 정상으로 예측해도 accuracy는 99%가 된다. 이런 경우 precision, recall, F1-score를 함께 봐야 한다.

로지스틱 회귀는 baseline model로도 유용하다. 복잡한 딥러닝 모델을 쓰기 전에 로지스틱 회귀로 어느 정도 성능이 나오는지 확인하면, 문제가 feature 부족인지 모델 표현력 부족인지 감을 잡기 쉽다.

## 의사결정트리

의사결정트리는 데이터를 `if-else` 조건으로 계속 나누는 모델이다. 루트 노드에서 시작해 내부 노드를 거쳐 최종 리프 노드에서 예측값을 낸다.

트리는 각 분기에서 데이터를 더 잘 나누는 기준을 찾는다. 분류 문제에서는 impurity를 줄이는 방향으로 split을 고르고, 정보 이득이 큰 feature를 우선 선택한다. CART 계열 트리는 이런 방식으로 트리를 구성한다.

의사결정트리의 장점은 사람이 이해하기 쉽다는 점이다. 하지만 트리가 너무 깊어지면 훈련 데이터에 과적합되기 쉽다. 그래서 depth 제한, leaf 최소 샘플 수 같은 규제가 중요하다.

트리 모델은 feature scaling에 민감하지 않다. 선형 모델처럼 거리나 기울기에 직접 의존하지 않고, 특정 feature 값이 기준보다 큰지 작은지를 기준으로 split하기 때문이다. 그래서 tabular data에서는 전처리 부담이 상대적으로 적다.

다만 작은 데이터 변화에도 트리 구조가 크게 바뀔 수 있다. 이런 불안정성을 줄이기 위해 여러 트리를 함께 사용하는 Random Forest 같은 앙상블 기법이 자주 쓰인다.

## 앙상블 모델

앙상블은 여러 모델의 예측을 합쳐 더 안정적인 성능을 얻는 방법이다. 하나의 모델이 가진 편향이나 분산을 여러 모델 조합으로 줄이는 것이 핵심이다.

대표적인 방식은 다음과 같다.

- Voting: 여러 모델의 예측을 투표로 합친다. hard voting은 클래스 투표, soft voting은 확률 평균을 사용한다.
- Bagging: 데이터를 여러 샘플로 나눠 모델을 병렬로 학습한다. Random Forest가 대표적이다.
- Boosting: 이전 모델이 틀린 샘플에 더 집중하면서 순차적으로 모델을 쌓는다. AdaBoost, Gradient Boosting 계열이 여기에 속한다.

앙상블은 단일 모델보다 성능이 좋아지는 경우가 많지만, 해석이 어려워지고 계산 비용이 늘어난다. 따라서 정확도가 중요한 문제에서는 강력하지만, 설명 가능성이 중요한 문제에서는 모델 선택을 신중히 해야 한다.

Random Forest는 bagging 방식이라 여러 트리를 독립적으로 학습한 뒤 평균 또는 투표로 결과를 합친다. 개별 트리는 과적합될 수 있지만, 여러 트리를 평균내면 분산이 줄어든다.

Boosting은 약한 모델을 순서대로 쌓아 이전 모델이 못 맞춘 부분을 보완한다. Gradient Boosting, XGBoost, LightGBM 같은 모델이 tabular competition과 실무에서 강한 성능을 보이는 이유가 여기에 있다. 대신 hyperparameter에 민감하고, 너무 많이 학습하면 과적합될 수 있다.

## 모델 선택 기준

처음부터 가장 복잡한 모델을 고르는 것보다 단순한 baseline에서 시작하는 편이 좋다. 선형 회귀나 로지스틱 회귀로 기본 성능을 확인하고, 비선형 패턴이 강하면 트리 기반 모델로 넘어가며, 성능이 더 필요하면 앙상블을 고려한다.

데이터가 작고 설명 가능성이 중요하면 단순한 모델이 더 적절할 수 있다. 반대로 feature 간 상호작용이 많고 정확도가 중요하면 tree ensemble이 좋은 출발점이 된다.

## 내가 이해한 핵심

선형 회귀와 로지스틱 회귀는 단순하고 해석하기 좋은 기본 모델이다. 의사결정트리는 조건 기반으로 데이터를 나눠 직관적이지만 과적합에 주의해야 한다. 앙상블은 여러 모델을 합쳐 성능을 높이는 실전적인 방법이다.

모델을 고를 때는 먼저 예측 대상이 연속값인지 클래스인지 보고, 그다음 데이터의 복잡도, 해석 가능성, 계산 비용을 함께 고려해야 한다.
