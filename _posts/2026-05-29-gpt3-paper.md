# GPT-3: Language Models are Few-Shot Learners

이 글은 논문 [Language Models are Few-Shot Learners](https://arxiv.org/pdf/2005.14165)를 바탕으로 정리한 글이다.

논문의 핵심은 간단하다. 언어 모델을 충분히 크게 만들면, task별 fine-tuning 없이도 prompt 안에 자연어 설명이나 몇 개의 예시만 넣어 다양한 NLP task를 수행할 수 있다는 것이다. 논문은 이 능력을 `in-context learning` 관점에서 보여준다.

![GPT-3 원문 Figure: aggregate performance across benchmarks]({{ '/assets/images/blog/gpt3-paper-figure.png' | relative_url }})

*출처: 논문 Figure 1.3. 모델 크기가 커질수록 zero-shot, one-shot, few-shot 성능이 함께 좋아지는 경향을 보여준다.*

## 1. 이 논문이 나온 배경

GPT-3 이전에도 대규모 pretraining 후 downstream task에 fine-tuning하는 방식은 강력했다. 하지만 이 방식에는 분명한 비용이 있었다.

- task마다 labeled dataset이 필요하다.
- task마다 fine-tuned checkpoint를 따로 만들고 관리해야 한다.
- 좁은 task dataset에 과하게 맞추면 spurious correlation을 학습할 수 있다.
- 사람이 새 task를 배울 때처럼 몇 개 예시만 보고 적응하는 능력과는 거리가 있다.

논문은 이 문제를 "모든 task에 대해 gradient update를 하는 대신, 언어 모델 자체가 prompt 안의 맥락을 보고 task를 수행할 수 있는가"라는 질문으로 바꾼다.

즉 GPT-3의 목표는 단순히 더 큰 언어 모델을 만드는 것이 아니라, 큰 모델이 task description과 examples를 읽고 즉석에서 task 형식을 파악하는지를 평가하는 것이다.

## 2. Few-Shot Learner란?

논문에서 말하는 few-shot learning은 모델 파라미터를 업데이트하는 fine-tuning이 아니다. inference 시점에 prompt 안에 예시를 넣는 방식이다.

```text
Translate English to French:

sea otter => loutre de mer
peppermint => menthe poivree
plush giraffe => girafe peluche
cheese =>
```

모델은 위 prompt를 보고 마지막 입력에 대해 같은 패턴으로 답을 생성해야 한다.

논문은 evaluation setting을 세 가지로 나눈다.

| 설정 | prompt에 들어가는 정보 | 파라미터 업데이트 |
|---|---|---|
| Zero-shot | task 설명만 제공 | 없음 |
| One-shot | task 설명과 예시 1개 제공 | 없음 |
| Few-shot | task 설명과 예시 여러 개 제공 | 없음 |

중요한 점은 세 경우 모두 gradient update가 없다는 것이다. 모델은 prompt context 안에서 task를 파악해야 한다.

![GPT-3 in-context learning 방식]({{ '/assets/images/blog/gpt-3.png' | relative_url }})

*GPT-3는 task별 fine-tuning 대신 prompt 안의 instruction과 examples를 조건으로 답을 생성한다.*

## 3. 모델과 학습 설정

GPT-3는 GPT-2 계열의 decoder-only Transformer 구조를 확장한 모델이다. 논문은 125M부터 175B까지 여러 크기의 모델을 학습해 scale에 따른 성능 변화를 비교했다.

![GPT-3 Transformer 구조]({{ '/assets/images/blog/gpt3-transformer-architecture.png' | relative_url }})

*GPT-3는 decoder-only Transformer 계열 모델이며, 다음 token 예측 objective로 학습된다.*

학습 목표는 language modeling이다.

```text
이전 token들 -> 다음 token 예측
```

논문에서 중요한 실험 설계는 가장 큰 모델 하나만 보여주는 것이 아니라, 다양한 model scale에서 zero-shot, one-shot, few-shot 성능이 어떻게 달라지는지 함께 본다는 점이다.

![GPT-3 training setup]({{ '/assets/images/blog/gpt-3-how.png' | relative_url }})

*논문은 여러 scale의 GPT-3 계열 모델을 학습하고, prompt-only setting에서 평가한다.*

## 4. 실험 결과 요약

논문은 language modeling, closed-book question answering, translation, Winograd-style reasoning, commonsense reasoning, reading comprehension 등 다양한 benchmark를 평가했다.

가장 큰 흐름은 다음과 같다.

- 모델 크기가 커질수록 few-shot 성능이 강하게 좋아진다.
- zero-shot보다 one-shot, one-shot보다 few-shot이 대체로 유리하다.
- 일부 benchmark에서는 fine-tuned SOTA와 경쟁하거나 앞선다.
- 하지만 모든 task에서 SOTA를 넘는 것은 아니며, 구조적으로 약한 task도 남아 있다.

### Language Modeling

![GPT-3 language modeling results]({{ '/assets/images/blog/gpt-3-score-01.png' | relative_url }})

*LAMBADA 같은 language modeling benchmark에서는 큰 모델과 few-shot setting의 이점이 뚜렷하게 나타난다.*

LAMBADA는 긴 문맥을 이해해 마지막 단어를 맞히는 benchmark다. 논문은 GPT-3가 이 task에서 강한 성능을 보였다고 설명한다. 이는 모델이 긴 context 안의 의미 관계를 활용할 수 있음을 보여준다.

다만 StoryCloze, HellaSwag처럼 상식적 결말이나 상황 추론이 필요한 task에서는 모든 경우에 압도적인 성능을 보인 것은 아니다.

### Closed-Book QA

![GPT-3 closed-book QA results]({{ '/assets/images/blog/gpt-3-03.png' | relative_url }})

*Closed-book QA는 외부 문서 검색 없이 모델 내부 지식만으로 답해야 하는 설정이다.*

TriviaQA 같은 task에서 GPT-3 few-shot은 강한 결과를 보였다. 하지만 closed-book QA는 모델이 학습 중 본 지식과 prompt 해석에 크게 의존한다. 따라서 검색 기반 QA처럼 근거 문서를 보고 답하는 방식과는 성격이 다르다.

### 다양한 NLP Task

![GPT-3 multilingual and task results]({{ '/assets/images/blog/gpt-3-04.png' | relative_url }})

*논문은 translation, commonsense reasoning, reading comprehension 등 여러 task에서 GPT-3의 prompt-only 성능을 평가했다.*

GPT-3는 영어 중심 데이터로 학습되었지만, 일부 translation task에서도 의미 있는 성능을 보였다. 이는 대규모 language modeling만으로도 어느 정도 cross-lingual pattern을 학습할 수 있음을 보여준다.

하지만 논문은 GPT-3가 모든 task에서 fine-tuned model을 대체한다고 주장하지 않는다. 특히 자연어 추론처럼 두 문장의 관계를 정밀하게 판단해야 하는 task에서는 상대적으로 약한 결과도 있었다.

## 5. 왜 모델 크기가 중요했나?

GPT-3 논문의 핵심 관찰 중 하나는 scale에 따른 성능 변화다.

작은 모델도 prompt 형식은 따라 할 수 있다. 하지만 task를 실제로 일반화하고, 예시에서 규칙을 뽑아내고, 긴 문맥을 유지하는 능력은 모델 크기가 커질수록 뚜렷하게 좋아졌다.

이 점은 이후 LLM 연구에 큰 영향을 줬다. GPT-3는 "모델을 task별로 계속 fine-tuning하는 방식"에서 "큰 foundation model을 만들고 prompt로 task를 지정하는 방식"으로 연구 관점을 이동시킨 논문에 가깝다.

## 6. 한계점

GPT-3는 강력하지만 논문에서도 한계를 분명히 다룬다.

### reasoning과 일관성 문제

GPT-3는 그럴듯한 문장을 만들 수 있지만, 긴 reasoning이나 multi-step logic에서는 실수할 수 있다. 이는 이후 Chain-of-Thought 같은 prompting 연구가 등장한 배경이기도 하다.

### fine-tuned model보다 약한 task가 있다

Few-shot prompting은 범용성이 크지만, 특정 task에 충분한 labeled data가 있고 fine-tuning을 할 수 있다면 fine-tuned model이 더 강할 수 있다.

### 생성 품질과 사실성 문제

긴 문장을 생성할수록 앞뒤 일관성이 흔들리거나, 사실처럼 보이지만 틀린 내용을 만들 수 있다. 이 문제는 LLM hallucination과 alignment 연구로 이어졌다.

### 비용과 접근성 문제

175B 규모 모델은 학습과 추론 비용이 매우 크다. 따라서 GPT-3가 보여준 성능 향상은 기술적으로 중요하지만, 누구나 쉽게 재현할 수 있는 방식은 아니었다.

## 7. 이 논문의 핵심 의의

이 논문의 의의는 "GPT-3가 모든 task를 해결했다"가 아니다.

더 정확히는 다음을 보여준 것이다.

- language model scale이 커지면 prompt-only task adaptation 능력이 나타난다.
- task별 gradient update 없이도 prompt 안의 예시를 보고 task 형식을 따라갈 수 있다.
- pretraining된 하나의 큰 모델이 여러 task에 범용적으로 사용될 수 있다.
- 평가 방식이 fine-tuning 중심에서 zero-shot, one-shot, few-shot prompting 중심으로 확장되었다.

이 흐름은 이후 instruction tuning, RLHF, ChatGPT, CoT prompting, tool use 연구의 기반이 되었다.

## 내가 이해한 핵심

GPT-3 논문은 LLM 시대를 여는 데 큰 역할을 한 논문이다.

핵심은 다음과 같다.

```text
task별 fine-tuning 대신
prompt 안에 instruction과 examples를 넣고
큰 language model이 그 맥락을 보고 task를 수행하게 한다.
```

이 방식은 모델을 더 유연하게 만들었지만, reasoning, 사실성, 비용, alignment 같은 새로운 문제도 함께 드러냈다.

## 한 줄 요약

GPT-3는 대규모 decoder-only language model이 prompt 안의 예시만으로 다양한 task에 적응할 수 있음을 보여주며, fine-tuning 중심 NLP에서 prompting 중심 LLM 시대로 넘어가는 계기를 만든 논문이다.
